# 유튜브 업로드 헬퍼

**영상 URL이나 재생목록 URL**을 넣으면 노래를 자동으로 찾아서 유튜브 업로드용 **제목 후보 · 설명 · 태그 · 해시태그** 초안을 만들어 주는 로컬 웹앱입니다. 결과를 복사해서 YouTube Studio에 붙여넣기만 하면 됩니다.

AI 분석은 **이 PC에 설치된 Claude Code CLI(`claude -p`)** 로 돌립니다. API 키가 필요 없고, 로그인된 Claude 계정 사용량으로 처리됩니다.

## 동작 방식
1. **받기**: `yt-dlp`로 URL의 영상을 받습니다(720p 이하). 유튜브, 인스타그램, 틱톡, X, 직접 링크 등을 지원하며, 원본 페이지의 제목·설명·태그도 함께 가져옵니다.
2. **추출**: ffmpeg로 오디오 클립 4개(앞 10% 건너뜀, 12초씩)와 프레임 10장을 뽑습니다.
3. **노래 인식**: Shazam(`shazamio`)으로 클립마다 인식한 뒤 다수결로 정합니다. ACRCloud 키가 있으면 그쪽을 먼저 씁니다.
4. **화면 분석**: Claude가 프레임 이미지를 읽고 자막, 네임 캡션, 방송 로고, 영상 유형(직캠/무대/커버 등)을 파악합니다.
5. **웹 보강**: Claude가 WebSearch/WebFetch로 한글/영문 곡명, 그룹, 앨범, 발매일, 크레딧, 팬덤 검색어를 확인합니다.
6. **생성**: 위 근거만으로 메타데이터를 만들고, 유튜브 제한(제목 100자, 설명 5000자, 태그 합계 500자, `<>` 금지 등)에 맞게 자동으로 보정합니다.

## 재생목록
URL 칸 하나로 영상과 재생목록을 자동으로 구분합니다.
- `youtube.com/playlist?list=...` 같은 재생목록 주소 → 안의 영상을 모두 분석 (최대 100개, `HELPER_PLAYLIST_MAX`)
- `watch?v=...&list=...` 처럼 영상과 재생목록이 함께 든 주소 → 기본은 그 영상 하나. "재생목록 전체 분석"을 체크하면 목록 전체
- 영상은 한 번에 하나씩 차례로 분석합니다 (`HELPER_CONCURRENCY`로 동시 개수 조절). 보관함에 이미 있는 영상은 건너뛰고 바로 완료 처리합니다.
- 진행 화면에서 영상별 상태를 보고, 끝난 영상은 "열기"로 바로 확인하며, 아직 시작하지 않은 영상은 "남은 영상 취소"로 멈출 수 있습니다.
- 힌트는 재생목록의 모든 영상에 똑같이 적용됩니다. 보관함에는 어느 재생목록에서 왔는지 표시되고 검색됩니다.
- 영상 1개에 약 2~3분이 걸리므로 30개짜리 재생목록은 1시간 넘게 걸릴 수 있습니다. 진행 중에 페이지를 새로 열어도 진행 상황을 이어서 보여 줍니다(서버를 끄면 남은 작업은 사라집니다).

## 보관함
분석 결과는 모두 **보관함** 탭(`data/helper.db`, SQLite)에 쌓입니다.
- 목록: 썸네일, 원본 제목, 곡, 분석 날짜, 상태. 제목·곡·힌트·메모로 검색하고 상태로 거를 수 있습니다.
- 상세: 제목 후보 중 쓸 제목을 고르고, 설명·태그·해시태그를 고쳐 **저장**합니다. 저장할 때도 유튜브 글자 제한에 맞게 보정합니다.
- 상태(초안 / 업로드 완료 / 보류)와 메모를 남길 수 있습니다.
- AI가 처음 만든 내용은 따로 보관되어 **원본으로** 버튼으로 되돌릴 수 있습니다.
- **다시 분석**: 같은 URL을 새로 분석해 새 항목으로 추가합니다. **삭제**: 보관함에서 지웁니다.

같은 URL과 같은 힌트를 다시 넣으면 보관함의 결과를 바로 보여 줍니다(Claude를 다시 호출하지 않음). 새로 분석하려면 "캐시 무시"를 체크하세요.

## 한계
- **얼굴로 멤버를 알아내지 않습니다.** 멤버 이름은 화면 자막, 원본 페이지 정보, **힌트 입력란**에서만 가져옵니다. 직캠이라면 힌트에 "뉴진스 하니 직캠"처럼 적어 주세요.
- 라이브 편곡이나 관중 소음이 심하면 오디오 인식이 실패할 수 있습니다. 이때는 화면과 페이지 정보, 힌트로 추정하고 경고와 "추정" 신뢰도를 표시합니다.
- `shazamio`는 비공식 라이브러리라 언젠가 동작하지 않을 수 있습니다. 그럴 때는 `.env` 에 ACRCloud 키를 넣으면 됩니다.
- 영상 1개 처리에 약 2분이 걸립니다(대부분 Claude 단계).

## 설치와 실행 (Windows)
사전 준비: [Claude Code](https://claude.com/claude-code)를 설치하고 터미널에서 `claude` 를 한 번 실행해 로그인합니다.

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env      # 필요하면 HELPER_MODEL 등 수정
.venv\Scripts\uvicorn app.main:app
```
브라우저에서 http://localhost:8000 을 엽니다.

- ffmpeg를 따로 설치하지 않아도 됩니다(`imageio-ffmpeg` 번들 사용). PATH에 ffmpeg가 있으면 그걸 씁니다.
- Python 3.10–3.13 (3.13은 `audioop-lts` 가 자동 설치됨).
- 모델은 `.env` 의 `HELPER_MODEL` 로 바꿉니다(`opus` 기본, `sonnet` 이 더 빠름).
- CLI는 격리 모드로 호출합니다. 사용자의 CLAUDE.md, 설정, MCP 커넥터는 적용되지 않고, 화면 분석에는 `Read` 도구만, 웹 보강에는 `WebSearch`/`WebFetch` 도구만 허용합니다.

## 구조
```
app/
  main.py            FastAPI 엔드포인트 (/api/jobs, /api/analyses CRUD, /api/health)
  store.py           보관함 (SQLite)
  jobs.py            단계별 파이프라인, 진행 상태, 결과 캐시
  download.py        yt-dlp 다운로드 + 원본 페이지 메타데이터
  media.py           ffmpeg 추출
  recognize/         Shazam·ACRCloud 어댑터, 투표
  llm/               client(claude -p 래퍼) · vision · research · compose
  youtube_rules.py   유튜브 제한 검증/보정
  static/            웹 UI
tests/               pytest
```
